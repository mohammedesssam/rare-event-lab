## Run

Python 3.10 was tested. In a fresh virtual environment:
```bash
python -m pip install -r requirements-dev.txt
python -m uvicorn app.api:app --host 127.0.0.1 --port 8000
# Open http://127.0.0.1:8000
python -m pytest -q
# Reproduce data generation and full training:
python -m app.train
```

The included artifact serves without retraining. Only load trusted joblib/pickle artifacts, because loading them can execute code. UI uses `/example` for a synthetic vector and `/predict` for classification. `/metrics`, `/docs`, `/health` are available. The prediction contract is 12 finite anonymous numeric features, each between -30 and 30; no personal records are accepted or needed. Scores are not calibrated confidence.

## Data and method

`make_classification`: 12,000 samples, 12 features, 6 informative, 3 redundant, weights [0.95,0.05], flip_y=0, class_sep=1, random_state=42. Features have no real-world units or financial meaning. IID stratified train/validation/test: 7,200 / 2,400 / 2,400, with 360 / 120 / 120 positives. All split indices are saved; no overlap.

Training-only imputer/scaler shared through a scikit-learn pipeline. Compare logistic regression, balanced logistic regression and histogram gradient boosting. Select the model by validation **average precision**. Choose the threshold by maximum validation F2 over 0.01 to 0.99. No oversampling or test-set threshold tuning. Test labels are never model inputs.

## Actual held-out results

Selected model: gradient boosting, threshold about 0.10.

| Metric | Selected threshold 0.10 | Default threshold 0.50 | Always negative |
|---|---:|---:|---:|
| Average precision | 0.8596 | 0.8596 | 0.0500 |
| ROC-AUC | 0.9819 | 0.9819 | 0.5000 |
| Precision | 0.6456 | 0.9059 | 0 |
| Recall | 0.8500 | 0.6417 | 0 |
| F2 | 0.7994 | 0.6814 | 0 |
| Accuracy | 0.9692 | 0.9788 | 0.9500 |

Selected confusion matrix, rows=actual negative/positive, columns=predicted negative/positive: `[[2224,56],[18,102]]`. Lowering the threshold catches 102 of 120 positives instead of 77, at the cost of 56 false positives instead of 8. An always-negative model looks good by accuracy but misses all positives. Average precision summarizes the precision-recall curve across thresholds; its value is not a classification accuracy percentage.

## Test and deployment status

Automated tests cover split separation, metric recomputation, API validation, deterministic predictions and offline/online parity. Exact outputs are in `reports/`. Model selection and threshold are frozen before test evaluation. All comparisons are on one synthetic IID sample; new real-world data would need independent validation, cost-based threshold design, drift checks and probability calibration. F2 reflects a chosen teaching preference for recall, not a verified business cost ratio.

Local HTTP/UI execution is checked separately in `reports/browser_check.json`. Dockerfile and CI workflow are included as deployment preparation, but not proof of cloud/container execution. To try Docker yourself: `docker build -t rare-event-lab .` then `docker run --rm -p 8000:8000 rare-event-lab`. Public hosting requires the owner's approval, cost/security review and live verification. No cloud service is claimed here.
